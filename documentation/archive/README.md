# Knowledge-Base Archive

## A. Purpose

1. This role holds superseded documents, migration evidence, source inventories, and audit registers.
2. Archived material preserves traceability but is not current system truth.

---

## B. Admission Rules

1. Scan every source before archiving it.
2. Record whether the source was absorbed, partially absorbed, superseded, retained as a compatibility shim, or intentionally excluded.
3. Confirm every durable fact has a canonical destination.
4. Keep extraction ledgers and migration checklists outside canonical documentation.
5. Do not archive a file that active repository instructions or scripts still require.
