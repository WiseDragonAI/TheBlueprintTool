## A. Mission

1. **The delivery** `establishes` one owner-aware Markdown authoring system for `federated-skill`, `workspace-skill`, `pipeline-prompt`, and locally owned Task card descriptions.
2. **The editor** `uses` pinned CodeMirror `6.0.2` in an `80vw` by `95vh` modal, while `@pierre/diffs` `1.2.12` `presents` complete Git revisions with red removals, blue additions, and non-color semantics.
3. **The release authority** `becomes` one non-interactive `decision-os-delivery` CLI that `promotes` one admitted `origin/dev` SHA, `deploys` the production relay, `activates` every project-owning node, and `proves` release identity plus federation convergence.

---

## B. Authoring Boundary

1. **Server-owned identities** `govern` every read and mutation. Direct Markdown paths `resolve` to canonical card, thread, skill, and pipeline-prompt routes; they never `grant` browser-selected filesystem access.
2. **Task card descriptions** `save` through scoped `patch-card` authority before the focused Git revision. **Thread files** `remain` note-owned and `open` the canonical thread surface without whole-file replacement.
3. **Pipeline prompts** `remain` absent from natural agent and federation discovery. Pipeline admission `pins` clean committed bytes, revision, and commit into an immutable run snapshot and `fails` closed when that evidence changes.

---

## C. Selected Control Architecture

1. **One stable editor session** `owns` the draft, dirty state, navigation protection, focus return, save recovery, and revision selection without remounting the editable `EditorView`.
2. **Git** `owns` authored history through bounded asynchronous processes, repository-wide mutation serialization, focused temporary-index commits, explicit recovery after preserved-byte failures, and uncapped cursor traversal.
3. **One durable delivery journal** `records` admission, phase receipts, node predecessors, relay versions, compensation, and terminal proof while Git refs, Cloudflare, node release pointers, MultiTerm, health, and federation diagnostics `remain` authoritative.
4. **Immutable detached releases** `protect` dirty operator checkouts. Each node `activates` an atomic stable release pointer and `restarts` through its declared supervisor; runtime rollback `restores` node pointers and relay traffic without rewriting published `main`.

---

## D. Verified Position

1. **The canary topology** `exists` with production `50150`, canary `50151`, and development relay `50152`, but the current authoring implementation `remains` an uncommitted development iteration and `is not` an admitted release.
2. **The current source state** `differs` from `origin/dev`, `does not contain` current `origin/main`, and `has not produced` complete automated plus served interaction evidence for the expanded contract.
3. **Direct Markdown routing and distributed delivery** `remain` incomplete: unmatched Markdown paths still `reach` the JSON fallback, active nodes do not expose delivery protocol `1`, and no end-to-end delivery CLI currently `owns` promotion, restart proof, relay deployment, resume, and compensation.
4. **Production runtime and relay state** `remain` outside the implementation boundary. No production promotion `is authorized` by the current evidence.

---

## E. Admission Gates

1. **Production mutation** `is forbidden` until one clean pushed `origin/dev` SHA has complete canary, verification, configuration, and interaction evidence recorded in its admission receipt.
2. **Every active project-owning node** `must be` online, bootstrapped to delivery protocol `1`, supervisor-adopted, repository-compatible, healthy, idle, and converged before `main` changes. The verified first-release bootstrap targets `are` `workstation` and `phone`.
3. **The relay gate** `requires` distinct canary configuration, pinned Wrangler `4.111.0`, non-interactive credentials, captured predecessor deployment, protocol compatibility, and release-SHA health proof.
4. **Any admission mismatch** `exits` before pushing `main`, changing relay traffic, switching a node pointer, stopping a process, and restarting a process.

---

## F. Operator Action

1. **No product decision** `remains`. The implementation, bootstrap, canary proof, and admission receipt `must complete` before production action.
2. **The operator** `must withhold` promotion until the CLI reports the exact admitted `origin/dev` SHA and every admission gate as satisfied.
3. **The sole production action** `is`:

   `decision-os-delivery promote --release-sha <40-character-origin-dev-sha> --server http://127.0.0.1:50150 --json`

4. **A successful decision** `requires` exit code `0` and one terminal result proving the published `main` SHA, active relay version, restarted node identities, active node SHAs, restored catalogs, and federation convergence.
