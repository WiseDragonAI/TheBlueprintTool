## A. Workflow

1. **Get the zone:** Run `node "$LEDGER_CLI" card-context --ledger <ledger-file> --card-id <card-id> --json` and use the returned `zone.id`.
2. **Get the zone cards:** Run `node "$LEDGER_CLI" zone-cards --ledger <ledger-file> --zone-id <zone-id> --json` and use the returned `cards[]`.
3. **Read the cards:** Read every source card `contentFile`, excluding the bridge card itself.
4. **Write the bridge card:** Replace the bridge card with one H2 section per source card, in zone order. Each section uses a lettered heading, `---` dividers, 3 to 5 numbered items, `**Content path:**` first, bold labels, and backticks for exact paths and ids.
