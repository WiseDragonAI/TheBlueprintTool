## A. Gate Objective

1. Build the feature-preservation baseline and one migration plan from the accepted contract.
2. Trace affected behavior across entry points, state transitions, persistence, network boundaries, background work, failure handling, and operator recovery.

---

## B. Required Evidence

1. Link every preserved behavior to current source symbols, existing tests, durable state, API contracts, UI paths, and runtime evidence.
2. Define ordered migration stages, data transitions, compatibility boundary, rollback point, observability, and acceptance proof.
3. Identify missing baseline coverage that must be added before behavior-changing edits.

---

## C. Exit Condition

1. Produce one evidence-backed migration plan with complete behavior invariants and explicit stage gates.
2. End with `READY_FOR_QUALITY_AUDITS` only when each affected workflow has a preservation check.
