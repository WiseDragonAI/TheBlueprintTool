## A. Objective

1. Derive every artifact lookup and operator-facing projection from persisted per-run ownership and one lifecycle DTO.

---

## B. Verified Evidence

1. History uses one current output path; moved deletion derives current ledger.
2. Promotion fabricates a path for an old run.
3. Control Room compares runtime execution with itself.
4. Local navigation omits active execution; federation omits history.

---

## C. Implementation Contract

1. Resolve read, continuation, move, promotion, stop, and deletion through `codexThreadRunOutputFiles[runId]`.
2. Preserve the promoted run's artifact path.
3. Build navigation, federation, Control Room, and events from one typed projector.
4. Require exact card, queue, runtime, run, and execution equality before active projection.
5. Reconcile contradicted projections at startup.

---

## D. Acceptance Tests

1. Moved-card operations use the real artifact directory.
2. Control Room rejects mismatched execution IDs.
3. Local and federated projections expose identical fields.
4. Reconciliation clears contradicted active pointers without deleting terminal history.
