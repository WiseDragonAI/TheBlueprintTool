## A. Scope

1. **Objective:** Project each OpenAI-format server skill into one zone, one primary card, and one card per reference file, synchronized with `.skills`.

---

## B. Requirements

1. **Ledger:** Use server `.decision-os/skills.json` as the registry ledger.
2. **Primary card:** Mirror `SKILL.md` exactly in one main card content file.
3. **Reference cards:** Mirror every `references/**` file exactly in its own card content file.
4. **Mappings:** Store `skillName`, `skillRole`, and `skillFile` on every card and label main-to-reference relationships with relative paths.
5. **Update:** Preserve mapped ids, add new references, and remove stale reference cards plus relationships.
6. **Resolution:** Inject the server `.skills` root into every project skill scan with synchronized names taking precedence.
7. **Tests:** Cover one-to-many projection, deterministic geometry, exact mirrors, stable update ids, stale removal, and two managed projects.
