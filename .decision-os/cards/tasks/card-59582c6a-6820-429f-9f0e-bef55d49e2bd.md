## A. Root Cause

1. `taskFrom()` evaluated runtime only on the master, then used `subtask` relationships solely for progress.
2. The referenced `rudy` child owned a pending lease while its master remained `task-waiting`.
3. Copying the lease to the master would create a false second owner.

---

## B. Selected Model

1. Keep leases card-local.
2. Aggregate only canonical relationship-backed members in the server projector.
3. Select `codex-process`, then `voice-transcription`, then `codex-queue`.
4. Preserve the selected owner through federation.
