## A. Scope

1. **Objective:** Change project creation to atomically initialize a canonical `tasks` ledger and register it in `state.json`.

---

## B. Acceptance Criteria

1. **Ledger registration:** A new project has exactly one initial ledger with id and title `tasks`.
2. **Ledger file:** The referenced JSON file exists and contains an empty valid ledger.
3. **Failure cleanup:** Any initialization failure removes the partially created project directory.
4. **Regression:** Unit and integration tests cover the response and persisted files.
