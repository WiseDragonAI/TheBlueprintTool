## A. A. Runner contract

1. One manifest schema covers thread, continuation, and pipeline skill runs.

---

2. One launcher starts a new host process session with prompt input and JSONL/log output bound directly to files.

---

3. One reconciler derives lifecycle from the manifest, validated OS identity, and terminal JSONL evidence.

---

4. One cancellation path validates process identity and signals the persisted process group.

---

5. All transitions are revisioned and idempotent so restart and duplicate reconciliation cannot advance a pipeline or release capacity twice.

---

## B. B. Server boundary

1. The server schedules requests, serves status, and publishes projections.

---

2. The Codex process, file transport, liveness, and terminal truth survive without the server.
