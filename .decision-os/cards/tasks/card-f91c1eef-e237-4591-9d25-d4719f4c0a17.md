## A. Scope

1. **Objective:** Let an agent create and update synchronized Skills ledger and `.skills` package representations through `ledger-cli` from the Decision OS server launch directory.

---

## B. Corrected Contract

1. **Commands:** Implement `skills create --source <skill-directory> [--json]` and `skills update --source <skill-directory> [--json]`.
2. **Server root:** Resolve the only server root from `process.cwd()` and reject `--root`.
3. **First run:** `skills create` provisions `.decision-os/skills.json`, registers the `Skills` ledger in `.decision-os/state.json`, and creates its canonical card in `.decision-os/ledgers-canvas.json` when these files do not exist.
4. **Package validation:** Validate `SKILL.md`, `agents/openai.yaml`, referenced resources, symlinks, paths, and readability.
5. **Writes:** Synchronize the `.skills` package, primary card, reference cards, relationships, card Markdown, thread mappings, thread files, and first-run registry files as one rollback-safe transaction.
6. **Create:** Reject an existing skill name and commit with `skills: create <skill-name>`.
7. **Update:** Reject a missing skill name, reconcile changed reference files, and commit with `skills: update <skill-name>`.
8. **Tests:** Cover CWD inference, explicit-root rejection, first-run provisioning, create, update, malformed packages, missing references, duplicate create, missing update, stale reference removal, write rollback, commit rollback, focused staging, and JSON output.
