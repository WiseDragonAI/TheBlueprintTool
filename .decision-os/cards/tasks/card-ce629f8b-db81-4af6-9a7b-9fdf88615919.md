## D. Verification Failure

1. The initial served proof used an artificial Task-card history and never exercised `GateTest`.
2. The exact-route regression checks only that at least one addition has blue styling and an accessible label.
3. It does not assert baseline identity, exact additions, exact deletions, untouched context, canonical semantics, editing, save bytes, reload persistence, or conflict presentation.
4. Passing suites proved consistency with an incorrect acceptance contract.
5. The `1,000,000`-byte performance gate is deferred because functional correctness fails first.
