## A. Objective

1. Define one typed durable ownership schema for thread-session history, per-run artifacts, current retained session, and exact pending or running execution.

---

## B. Verified Evidence

1. `shared/schemas/core-types.ts` declares no Codex lifecycle fields.
2. Inventory contains 46 active-run values, zero active-execution values, 45 unmatched active pointers, and three legacy execution-status values.
3. `resolve-card-skill-run-files.ts` applies one current output reference to every historical run.

---

## C. Implementation Contract

1. Add typed `codexThreadRunId`, ordered `codexThreadRunIds`, `codexThreadRunOutputFiles`, `codexActiveRunId`, and `codexActiveExecutionId` fields.
2. Add exact run and execution identity to queue, runtime, pipeline execution, events, responses, and frontend summaries.
3. Implement an idempotent migration that maps retained runs to real artifact paths, clears unmatched ownership, removes legacy status, and emits counts.
4. Retain compatibility readers only for the migration window; all new writes use canonical fields.

---

## D. Acceptance Tests

1. Schema rejects contradictory nonterminal ownership and accepts terminal history without active fields.
2. Migration covers same-ledger history, moved cards, missing artifacts, repeated execution, and a second pass.
3. Post-migration inventory has no legacy status and no active run without active execution.
