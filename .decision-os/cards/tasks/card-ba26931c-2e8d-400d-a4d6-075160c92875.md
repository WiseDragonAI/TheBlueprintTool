## A. Result

1. **CLI:** `add`, `list`, `search`, and `migrate` now call the authenticated Cloudflare service and retain the existing command interface.
2. **Configuration:** Environment values override server-root settings, which override the shared ignored home settings. Transient Cloudflare `429` and `5xx` responses receive three bounded retries.
3. **Server:** Removed local SQLite provisioning and the obsolete runtime database path.
