## B. Root cause

1. The original implementation navigated from `onPersisted`, which fires before `submitPendingVoiceUpload` completes.
2. The first correction removed this premature callback but failed to restore navigation after the awaited upload result.
3. The first regression test asserted the wrong terminal state, so it could not detect the missing exit.

---

## C. Corrected implementation

1. Await `stopVoiceRecording({ queueCodex })` for both X variants.
2. When `queueCodex` is true and submission succeeds, invoke `finishQueuedVoiceSubmission(submitted)` to use the established Queue navigation.
3. When `queueCodex` is false, return without navigation.
4. When submission fails, retain the card and the locally persisted recording for retry.
