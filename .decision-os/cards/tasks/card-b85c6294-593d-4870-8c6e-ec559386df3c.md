Ledger: Specs

## A. Outcome

Ensure every durable Codex queue item is automatically reconsidered when the Decision OS server starts after an abrupt Termux shutdown.

---

## B. Evidence

1. **Contradicted result:** The operator restarted the merged server and the three pre-crash jobs did not launch.
2. **Actual root cause:** Startup changed every durable `running` thread claim to `interrupted`; the scheduler selects only `pending` records, and the previous regression covered only a record that had never been claimed.
3. **Correction:** Startup now converts a claimed thread into a pending continuation of the same durable run and requeues a claimed continuation without changing its run identity. Recovery resumes the captured Codex session and reconstructs a new session only when no session ID was persisted.
4. **Integration:** Implementation commit `a53d295` is merged into `main` by `b0b6445`.
