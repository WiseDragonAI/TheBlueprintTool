## A. Continuation Regression Coverage

1. Backend coverage proves execution parsing, durable finish timestamps, execution-scoped elapsed time, execution-scoped tool counts, and immutable execution identities.
2. Frontend coverage proves three continuations under one durable run render as `Run 1 of 3` through `Run 3 of 3`, hydrate only the selected execution's events, and display that execution's metrics.
3. Responsive source contracts distinguish selected historical metrics from the active session action state.
