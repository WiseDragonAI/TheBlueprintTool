## A. Expected Behavior

1. **Focused draft:** pressing `Escape` while `.thread-draft` has focus blurs the draft without closing the thread and without navigating.
2. **Master-task detail:** pressing `Escape` again when no editable control has focus activates the existing Back action and returns to the Control Room through `navigateTaskBack`.
3. **Voice precedence:** pressing `Escape` during voice recording cancels the recording before any blur or navigation transition.
4. **Visible shortcut:** the master-task Back button displays an `Esc` key hint.

## B. Scope

1. **Category:** desktop frontend keyboard navigation and shortcut affordance.
2. **Surface:** responsive card detail at desktop width, including its shared thread inspector.
3. **Preserved behavior:** non-master card navigation, Back click behavior, thread draft persistence, `X` voice capture, and the existing accessible Back transition remain intact.
