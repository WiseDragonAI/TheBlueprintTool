## A. Operator Request

1. Preserve every Codex run associated with a card thread when a later run starts.
2. Add previous and next arrow controls in `Codex Log` so the operator can inspect each retained run.
3. Keep the newest run selected by default while allowing the selected historical run to hydrate its complete log.

---

## B. Verified Current State

1. `projectCardCodexRun` replaces `codexThreadRunId` and `codexThreadRunOutputFile` whenever a thread run is projected.
2. `resolveCardSkillRunOwnership` authorizes status reads only through current run fields and legacy generated-card fallbacks.
3. `bindActiveThreadRun` and `renderThreadCodexLog` resolve one run through `cardCodexRunId`; client state is keyed only by thread.
4. Run artifacts are stored under `.decision-os/runs/codex-skills/<ledger>/`; a new launch loses the prior UI association without deleting those artifacts.
