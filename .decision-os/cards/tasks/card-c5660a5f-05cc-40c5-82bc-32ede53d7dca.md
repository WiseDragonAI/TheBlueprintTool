## A. Scope

Publish the complete operator and developer documentation for skill creation, editing, ownership, revision conflicts, export invalidation, dev server operation, MultiTerm registration, Wrangler relay isolation, verification, promotion, rollback, and cleanup.

---

## B. Acceptance

1. Every changed API includes request, response, validation, failure, and synchronization contracts.
2. Environment documentation identifies exact non-secret variables and ownership boundaries.
3. Relay documentation records compatibility and convergence checks.
4. The runbook provides one deterministic canary launch and removal sequence.
5. Documentation links the analysis and over-engineering decisions that constrained implementation.
