## A. Required Change

1. Add a shared shell command contract under `frontend/src/runtime/input` that records `commandId`, state owner, transition owner, pending policy, reconciliation policy, and keyboard binding.
2. Migrate the `90` static buttons in `frontend/index.html` into exactly one of three enforced ownership classes: delegated command, form submission, and component-private callback.
3. Consolidate `handleActionClick`, `bindInputs`, responsive application initialization, responsive Codex initialization, and responsive thread initialization around the contract.
4. Fail initialization in development and fail automated checks when a button has no owner, multiple owners, an unknown command, or a keyboard binding that invokes a different transition.

---

## B. State Boundaries

1. **Canvas state** remains owned by `frontend/src/runtime/state.ts`.
2. **Responsive route state** remains owned by the route snapshot and `frontend/src/app/responsive/application.js`.
3. **Thread state** remains owned by the thread module and active thread identity.
4. **Codex library state** remains owned by the Codex module and its generation guards.
5. The registry dispatches commands; it does not duplicate domain state.

---

## C. Completion Checks

1. An ownership test enumerates every static button and reports its single owner.
2. Every submit button is nested in one form whose submit handler is registered.
3. No command string is implemented by competing shell dispatchers.
4. Existing accessibility names, disabled semantics, and keyboard shortcuts remain unchanged unless the command contract identifies a verified mismatch.

---

## D. Dependencies

1. Depends on **Centralize Back and Close transition ownership**.
