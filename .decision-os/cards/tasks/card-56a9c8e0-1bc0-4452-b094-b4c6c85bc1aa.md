## A. Scope

1. **Objective:** Add a backend completion transaction that persists the completed ledger projection and creates one path-scoped Git commit.

---

## B. Requirements

1. **Included files:** Commit the active ledger JSON, master-task card Markdown, canonical subtask card Markdown files, and master-task thread Markdown.
2. **Excluded files:** Do not stage images, Codex run logs, or unrelated workspace changes.
3. **Rollback:** Restore touched files and the in-memory ledger when persistence or Git commit creation fails.
