## A. Visibility Trace

1. **Persisted:** the source task receives `codexPipelineStepName` and `codexSkillName` when each skill starts.

3. **Rendered:** the task row prints `Codex ${task.codexRunId}`; generated pipeline cards render the readable pipeline, step, and skill context.
4. **Finding:** the operator-visible run identifier is a presentation/read-model gap, not missing pipeline state.
