#master-task

Ledger: Specs

## A. Scope

1. **Objective:** Bring the verified Termux/Android Chromium runbook into the `decision-os` workspace and make it mandatory guidance for mobile browser tests and screenshots.
2. **Source:** Preserve the operational contract verified in `../doc/browser-runbook.md`.
3. **Lifecycle:** Keep this master task active until the operator explicitly authorizes completion.

---

## B. Requirements

1. **Local runbook:** Add `BROWSER_RUNBOOK.md` at the repository root with workspace-correct commands.
2. **Agent reference:** Require agents to read `BROWSER_RUNBOOK.md` before browser testing, debugging, automation, and screenshot capture on the phone.
3. **Android launch contract:** Preserve `--no-sandbox`, `--no-zygote`, `--single-process`, `--disable-dev-shm-usage`, and `--disable-gpu`.
4. **Server safety:** State that browser automation must not restart, stop, or replace the Decision OS server.

---

## C. Acceptance Criteria

1. **Documentation:** `BROWSER_RUNBOOK.md` identifies the verified Chromium binary and browser helper paths.
2. **Discoverability:** `AGENTS.md` links to the local runbook and states when it is mandatory.
3. **Verification:** Documentation references match files present on this Termux device.
4. **Repository state:** The documentation change is committed without including unrelated workspace changes.
