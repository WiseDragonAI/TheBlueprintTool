## A. Scope

1. **Search:** add a search field to the Skills, Pipelines, and Card Processing lists.
2. **Project filters:** reuse the Control Room project chip treatment on global libraries.
3. **Tag filters:** add secondary chips for skill category, skill source, and pipeline skill categories.
4. **Card context:** keep Card Processing project-scoped while applying the same list filters.

---

## B. Acceptance Criteria

1. **Immediate filtering:** search and chips update results without page navigation.
2. **Clear state:** one clear action restores the complete list.
3. **Visible metadata:** every result shows project and relevant tags.
4. **Empty states:** filtered zero-result states distinguish no matches from an empty catalog.
