## A. Verified UI Contract

1. **Surface:** the Control Room `New task` dialog implemented by `openNewTaskProjectModal` in `frontend/src/app/responsive/application.js`, with markup in `frontend/index.html` and styling in `frontend/assets/application.css`.
2. **Node navigation:** group projects by `ownerNodeId` and expose one tab per node using `ownerNodeLabel` as the visible tab label.
3. **Default selection:** select the current local node on every dialog open using the project catalog's `remote: false` ownership record.
4. **Project content:** show only the project name inside the selected node's project list. Do not render project IDs in visible text or accessible names.
5. **Presence:** expose each node's `Online` or `Offline` state on its tab. Keep projects from an offline node visible when that tab is selected, while disabling their task-creation controls.
6. **Creation path:** keep `createTaskIntake(project.id)` and the existing busy, error, cancel, and focus behavior as the mutation boundary.
