## A. Reopened Architecture Analysis

1. **Observed failure remains open:** The operator reports that the Git waveform is still not visible. No further success claim is permitted without served-browser evidence.
2. **Paint-server isolation gap:** Every call to `waveSvg()` emits the fixed document IDs `waveAreaGradient` and `waveCoreGradient`, and every path references `url(#waveAreaGradient)` and `url(#waveCoreGradient)`. A card and its thread therefore contain duplicate SVG IDs and cross-widget fragment references instead of instance-owned paint resources.
3. **Ownership isolation gap:** `acquireVoiceCaptureOwnership(owner)` accepts a second acquisition when the stable owner string matches. A detached and a newly rendered copy of the same Git widget can consequently own concurrent capture sessions, while either copy can release the other copy's ownership.
4. **Lifecycle isolation gap:** Card replacement destroys the Git widget DOM without cancelling its `MediaRecorder`, animation frame, stream, audio context, or ownership. The Markdown widget exposes no disconnect or disposal contract.
5. **Verified local state boundary:** Git recorder data remains in its closure and does not read or write `state.voice`; the remaining defects are DOM resource identity, ownership lease identity, and component teardown.
6. **Required structural correction:** Give every waveform instance unique paint-resource IDs, replace owner-string arbitration with an opaque single-use lease, and dispose capture synchronously when the widget disconnects. Preserve the validated thread recorder implementation and styling.
7. **Evidence blocker:** The running port `50151` does not answer HTTP checks, so the served module version cannot be established. The exact operator URL, device, and browser are still required before implementation and served validation.
