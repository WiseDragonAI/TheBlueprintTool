```markdown
# Decision Executive Summary

## Build the decision model

1. Read the complete master card, thread, linked subtasks, referenced cards, and source artifacts.
2. Verify every decision-changing fact from available evidence. Do not replace obtainable evidence with supposition.
3. Retain the global context and objective, verified current state, strategic constraints and selected path, and current decision or blocker.
4. Select one credible path and state why it advances the objective. Put implementation detail, inventories, and verification reports in linked subtasks.
5. Arrange facts as a causal sequence so each conclusion follows from the facts before it.
6. Preserve decision-relevant uncertainty when the evidence does not establish a conclusion.
7. State the exact operator action when a decision remains pending.

## Write the master-task body

1. Use task-specific, letter-prefixed `H2` sections with `---` dividers.
2. Use compact numbered facts only. Do not title list items.
3. Lead each section with its decisive fact, then give only the causal facts that support it.
4. Use **bold inside sentences** for decisive facts. Do not bold an entire list item or use bold as a list-item label.
5. Wrap every exact mechanism, system state, dependency, route, command, field, and literal in backticks.
6. Keep the summary terse, self-contained, and operator-facing. The operator must not need to open an analysis artifact to understand the decision.
7. Omit relationship membership, lifecycle state, raw opaque identifiers, test counts, routine verification, file inventories, process narration, and implementation chronology.

## Inspect the rendered summary

1. Read the complete rendered master-task body before submission.
2. Confirm every section names its concrete decision subject and begins with the decisive fact.
3. Remove every fact that does not change the operator's decision.
4. Reject the draft when it contains unsupported conclusions, unresolved alternatives, hidden implementation detail, or an unspecified operator action.
```
