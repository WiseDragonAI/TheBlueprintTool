## A. Scope

1. Remove the materialized task projection, replay indexes, transferred state snapshots, and content replica cache from shared-branch authority.
2. Archive sealed immutable event segments and locally generated verified state snapshots asynchronously through writer-owned Git refs with independent destination status.
3. Keep code synchronization, intentional content commits, priority state delivery, asynchronous content replication, snapshot generation, and archival durability as separate workflows.
4. Ensure Git failure cannot change event dates, local acceptance, peer acknowledgement, checkpoint selection, projection output, or content-lane retry.

---

## B. Acceptance

1. Code pull and push succeed while local projections, indexes, state snapshots, event tails, and content caches differ.
2. Concurrent nodes archive immutable segments and snapshots without rewriting one shared ref.
3. Archival outage and recovery do not interrupt state replication, snapshot generation, or content retry.
4. Content replica cache files are local generated state and never staged by the existing intentional content workflow.
