## A. Scope

1. **Question:** Explain what Codex plugins are, what the `/plugins` directory represents, and why it contains hundreds of entries.
2. **Evidence:** Use current official OpenAI documentation and the installed Codex environment.
3. **Output:** Give the operator a concrete mental model, distinguish plugins from skills and connectors, and explain when installation is useful.
4. **Follow-up:** Identify prominent official and community plugins, give concrete use cases, and calibrate popularity claims using marketplace, GitHub, and Reddit evidence.

---

## B. Research Findings

1. **Plugin model:** A plugin is an installable bundle. It can contain reusable `skills`, authenticated apps/connectors, MCP tool servers, lifecycle `hooks`, browser capabilities, assets, and scheduled-task templates.
2. **Directory model:** `/plugins` opens a browser across marketplace catalogs. The official curated directory can be combined with repository and personal marketplaces. A marketplace is a JSON catalog, so a large list is inventory, not hundreds of capabilities already loaded into the current chat.
3. **Installation model:** Installing copies the selected bundle into the Codex plugin cache and records its enabled state. A new session is required before bundled skills and tools are available.
4. **Security model:** Connectors can request external-service authorization, MCP tools can read data and perform actions, and hooks run commands at lifecycle points. Review publisher, requested capabilities, authentication, and hooks before enabling a plugin.
5. **Local evidence:** `codex plugin marketplace list` reports `No plugin marketplaces in scope` in this shell. The large `/plugins` list therefore does not come from a repository marketplace configured in this CLI environment; the documented official curated directory is the verified built-in source that can still populate the browser.
6. **Sources:** [OpenAI plugin overview](https://learn.chatgpt.com/docs/plugins), [OpenAI plugin build and marketplace guide](https://learn.chatgpt.com/docs/build-plugins), and [OpenAI command reference](https://learn.chatgpt.com/docs/reference/commands).
7. **Popularity finding:** No authoritative public ranking exists because OpenAI exposes no public install counts. The official `openai/plugins` repository has about `1.3k` GitHub stars, while Reddit discussion shows adoption concentrated around service integrations and substantial disagreement about broad workflow packs.
8. **Engineering use cases:** `GitHub` connects repository, issue, pull-request, CI, and security-alert work; `Linear` connects issue planning and status updates; `Sentry` brings production errors and stack traces into debugging; `Vercel` adds platform guidance and deployment workflows.
9. **Design and application use cases:** `Figma` supports design context, design-system mapping, code generation, and editable canvas output; `build-web-apps`, `build-ios-apps`, `build-macos-apps`, and `Expo` package stack-specific implementation and debugging workflows.
10. **Knowledge-work use cases:** `Notion`, `Slack`, and `Google Drive` let Codex turn internal context into meeting briefs, research, plans, postmortems, incident plans, and feature tickets. OpenAI's role plugins extend this pattern to data analytics, creative production, product design, sales, and investing.
11. **Community finding:** Reddit users repeatedly mention external-service plugins as the highest-value category. `Superpowers` is the most visibly discussed workflow pack in the sampled thread, but users dispute its token cost and several prefer base Codex with narrowly tailored skills.
12. **Sources:** [OpenAI official plugin repository](https://github.com/openai/plugins), [OpenAI role-specific plugin use cases](https://openai.com/index/codex-for-every-role-tool-workflow/), [Vercel's official-plugin survey](https://vercel.com/i/codex-plugins), [Reddit community discussion](https://www.reddit.com/r/codex/comments/1sz8id5/best_codex_plugins/), and the [independent Codex Plugin Marketplace](https://www.codex-marketplace.com/).
