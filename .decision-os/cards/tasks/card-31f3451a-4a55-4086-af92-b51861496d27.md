## A. Implemented transaction model

1. **Apply:** Canonical task labels and relationship-backed link-only Markdown are written in one plan transaction.
2. **Progress:** Content, titles, labels, verified JSON statuses, generated links, and one thread reply are preflighted and committed atomically.
3. **Rollback:** An invalid plan or write failure restores every affected ledger, card, and thread file.
4. **Guard:** Progress cannot update the master status to `done`.
