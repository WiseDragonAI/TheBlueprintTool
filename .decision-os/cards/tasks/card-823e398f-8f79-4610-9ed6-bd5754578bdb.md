## A. Editor

Build one reusable CodeMirror 6 adapter in an `80vw` by `95vh` modal with Markdown syntax, undo and redo, search, keyboard shortcuts, dirty and save states, accessible focus trapping, and toolbox actions. Clicking a Skills-library record opens its content.

---

## B. Revision Browser

Load the file history from Git, display the current revision identifier and timestamp, and provide previous and next controls. Render the selected revision against its successor through the existing `@pierre/diffs` `1.2.12` adapter. Apply blue addition styling and red removal styling with non-color signs, line numbers, and labels.

---

## C. Reuse Boundary

The editor accepts content, language, filename, revision, history, toolbar actions, and completion callbacks. Application services own persistence and Git. Add a code comment naming future thread-file click-to-edit reuse; exclude that future feature now.
