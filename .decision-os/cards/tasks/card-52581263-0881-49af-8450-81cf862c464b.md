## A. Delivered

1. **Storage decision:** Federated skills use the existing server `.skills` store. Federated pipelines use the existing server pipeline store. No parallel replica index is required.
2. **Durability:** Imported packages and definitions are ordinary local files, so consumers keep reading them when the owner node is offline.
3. **Conflict rule:** A same-name skill and a same-ID pipeline converge deterministically by update timestamp and content revision.
