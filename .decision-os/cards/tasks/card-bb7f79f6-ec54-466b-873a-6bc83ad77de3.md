## A. Scope

Add the missing skill creation endpoint and connect it to the Skills interface. Generate a valid `SKILL.md` from the supplied name, description, initial instructions, and ownership checkbox, then return the created skill with its current revision.

---

## B. Acceptance

1. Validation covers names, duplicates, containment, payload size, and source-root authorization.
2. Creation is atomic and cannot overwrite an existing skill.
3. The created skill appears immediately in the Skills list.
4. Federated creation refreshes and publishes the existing export index; local creation does not.
