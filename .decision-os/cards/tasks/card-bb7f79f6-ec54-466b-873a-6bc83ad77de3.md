## A. Scope

Add the missing creation API and Skills-interface control for `federated-skill`, `workspace-skill`, and `pipeline-prompt`. Generate valid `SKILL.md` only for agent-visible kinds. Persist pipeline prompts in pipeline-owned storage and return content, kind, revision, Git-history head, and execution visibility.

---

## B. Acceptance

1. Validate name, kind, collision, containment, payload size, and root authorization.
2. Creation is atomic and cannot overwrite existing content.
3. The new record appears immediately with a clear kind label.
4. Federated creation refreshes the existing export index; workspace skills and pipeline prompts do not.
5. Successful creation produces the initial scoped Git revision; failed creation produces none.
