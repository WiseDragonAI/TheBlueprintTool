#master-task

Ledger: Specs

## A. Objective

1. **Use the active project color as the default for every newly created zone.**
2. **Realign existing zones that own Mastercard task hierarchies to the current project color without recoloring unrelated zones.**

---

## B. Verified Cause

1. The project-state endpoint already exposes `projectColor`.
2. The client does not store that value and initializes `state.zoneColor` to `#55b8ff`.
3. Cards inherit their accent from their owning zone, so task cards under default-colored zones remain cyan.

---

## C. Acceptance

1. A new zone is created with the active project color.
2. Mastercard zones and their linked subtask cards inherit the project color.
3. Unrelated existing zones retain their current colors.
4. Focused automated checks pass and the served project route is verified.

---

## E. Retrospective
