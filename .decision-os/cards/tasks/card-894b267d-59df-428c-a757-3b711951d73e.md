## A. Required Outcome

1. **Every accepted interaction is durable on the receiving node before acknowledgment.** Notes, voice transcription lifecycle, images, direct Run requests, and Pipeline requests first persist their intent and pending state in the local Epoch 4 journal.
2. **Relay transport is asynchronous publication.** Local mutation admission never waits for relay convergence. Replicated state converges through CRDT deltas after the local transaction commits.
3. **Payload replication is selective.** Transcription text and content heads replicate. Raw voice audio stays node-local. Image originals and deterministic previews transfer only by exact-hash demand.
4. **Events do not author domain state.** Browser and federation events carry revision-aware invalidations. Repositories and scoped reads own the installed projection.

---

## B. Ordered Implementation Gates

1. Atomically persist note identity, pending status, threadFiles/<threadId>, and the resulting Markdown content head.
2. Replace remote task mutation proxying with a locally journaled writable replica and asynchronous CRDT publication.
3. Route voice acceptance and every transcription transition through the same local mutation path while excluding raw audio from replicated resource heads.
4. Persist execution queued state before direct Run and Pipeline scheduling.
5. Convert interaction events into revision-aware invalidations and ignore revisions already installed locally.
6. Make image upload locally transactional and publish original plus deterministic preview heads for on-demand transfer.
7. Add offline, restart, rejection, delayed-relay, duplicate-event, direct Run, Pipeline, and fresh-reload regressions.
8. Execute the one-time orphan-thread repair only after gates 1 through 7 pass.

---

## C. Persistence Contract

1. Local acknowledgment follows the durable local journal commit and required local object installation.
2. Each multi-entity interaction uses one Epoch 4 batch, one revision boundary, and an atomic sidecar replacement when Markdown changes.
3. Remote-only project caches become writable replicas. They retain locally authored deltas until publication succeeds.
4. A rejected mutation reconciles the optimistic browser projection to the latest server-confirmed revision without deleting accepted local intent.
5. Queued execution exists durably before any scheduler wake-up, child-process launch, or pipeline successor dispatch.

---

## D. Content Contract

1. Raw voice audio, browser retry blobs, upload staging, child handles, and mutable live logs remain local-only.
2. Transcription status, transcription text, note state, execution lifecycle, artifact heads, image-original heads, and image-preview heads replicate eagerly as structural state.
3. Image bodies and immutable execution artifacts transfer on demand by exact hash.
4. The deterministic canvas preview profile is canvas-preview-v1 with a maximum 768-pixel longest edge while preserving aspect ratio. Full-detail reads demand the original.

---

## E. Verification And Completion

1. Prove optimistic UI before request settlement, successful fresh reload, and rejected-request reconciliation.
2. Prove accepted state survives server reconstruction from the journal and sidecars.
3. Prove local admission with relay unavailable and later convergence after delayed or duplicate delivery.
4. Prove direct Run and Pipeline never launch before durable queued state.
5. Prove raw audio is absent from replicated heads and image bodies remain demand-driven.
6. Run focused tests, scoped typechecks, and the repository full suite through decision-os-verify.mjs.
7. Run the orphan-thread repair, verify projection-to-sidecar identity and content heads, and retain repair evidence.
