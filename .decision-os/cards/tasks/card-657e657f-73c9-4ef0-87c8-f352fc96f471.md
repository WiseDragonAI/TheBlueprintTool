## A. Required Change

1. Migrate the `62` production `createElement('button')` sites across canvas, Codex, ledger, thread, voice, media, questionnaire, Git review, and responsive components to the shared command contract.
2. Keep local callbacks only when the component owns all mutated state and cleanup; register that component as the command owner at construction.
3. Require asynchronous commands to capture immutable resource identity and generation before dispatch, expose pending state, ignore stale completions, restore actionable state on rejection, and reconcile from server-confirmed state after success.
4. Remove duplicate element factories and duplicated action routing after each command family has one owner.

---

## B. Target Families

1. **Canvas:** tools, selection controls, card controls, zone controls, group controls, ledger indicator.
2. **Codex:** process library, pipeline library, editor, skill picker, run lifecycle controls.
3. **Ledger content:** status, delete, tabs, media, HTML embeds, questionnaires, Git review controls.
4. **Thread and voice:** notes, run log navigation, jump controls, composer actions, recording controls.
5. **Responsive lists:** project, directory, Control Room, zone, card, subtask, completion, creation, and settings controls.

---

## C. Completion Checks

1. Automated enumeration finds no unregistered dynamic button constructor.
2. Every async command test proves pending, successful reconciliation, rejected reconciliation, and stale-response suppression.
3. Component-private commands cannot mutate route, ledger, thread, and Codex state outside their declared owner.
4. Rendered labels, ARIA names, disabled states, and focus restoration remain correct.
