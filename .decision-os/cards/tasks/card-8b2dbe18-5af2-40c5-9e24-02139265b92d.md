## A. Scope

Create a dedicated `dev` branch and Git worktree from the current `main` tip. Define a canary server port, state boundary, log path, and MultiTerm registration that cannot stop, replace, or write through the production runtime.

---

## B. Acceptance

1. The canary starts independently through the repository launcher.
2. MultiTerm records the canary cwd, command, port, URL, and description.
3. Production remains reachable and unchanged.
4. Startup, health, rollback, and cleanup evidence is documented.
