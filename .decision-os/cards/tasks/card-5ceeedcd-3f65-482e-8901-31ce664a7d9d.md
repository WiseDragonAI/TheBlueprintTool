## A. Scope

1. Define the immutable atomic field-event schema and forbid sequence fields.
2. Define chronological reduction by `emittedAt`, insertion and replay for late events, set/add/remove/tombstone semantics, and explicit same-date conflicts.
3. Specify which entity fields form one atomic mutation and how a later dated event resolves a conflict.

---

## B. Acceptance

1. Schema and comparator tests reject sequences, non-date ordering, arrival ordering, aggregate replacement, and content payloads.
2. Every arrival permutation of one dated event set produces identical values and conflict metadata.
3. Equal-date incompatible writes remain visible and unresolved until a later resolution event.
