## A. Implemented Native Question Widget

1. **Surface:** a standalone `::questions[...]` Markdown directive now mounts a reusable question widget inside Decision OS cards.
2. **Reference fidelity:** the widget follows Senior's questionnaire structure: progress header, `LLM → operator` question card, four emoji choices, `W/E/S/D` shortcuts, free-text answer, irrelevant action, next action, copy action, and desktop queue rail.
3. **Responsive behavior:** desktop uses a two-column question-and-queue layout; mobile stacks the question surface and exposes the queue as a horizontal strip.
4. **Implemented commits:** `f5be4327`, `8808429c`, and `ea86ac8f`.

## B. Card Declaration

1. **Directive:** `::questions[Operator questions](questions:?id=implementation-context)`.
2. **Identity:** the query `id` selects one questionnaire from the owning card's `questionnaires` map.
3. **Thread boundary:** thread notes render a reference; the owning card detail renders the interactive controls.
4. **Reusable scope:** the same renderer is available on canvas card details and the responsive card view.

---

## C. Pipeline Output State

1. **Write command:** `ledger-cli mutate --ledger "$DECISION_OS_LEDGER_FILE" --card-id <card-id> --card-questionnaires-file <questionnaires.json>`.
2. **Questionnaire:** every entry stores `version: 1`, non-empty `contextRevision`, ordered questions, optional `currentQuestionId`, and responses keyed by question ID.
3. **Question:** each question stores stable `id`, precise `question`, exactly four `{ emoji, text }` choices, and `placeholder`.
4. **Response statuses:** `answered`, `rejected`, `skipped`, and `pending`; answered responses retain the choice index or custom answer with `updatedAt`.
5. **Revision safety:** changing `contextRevision` while carrying a prior non-pending response is rejected. The producing skill must emit the new revision with cleared responses.

---

## D. Interaction and Persistence

1. **Choice answer:** click, touch, `W`, `E`, `S`, and `D` select and submit the matching choice.
2. **Other answers:** `X` marks irrelevant, `C` skips to the next question, and `Ctrl+Enter` submits the custom textarea answer.
3. **Optimistic state:** the selected answer appears before the write completes; controls lock during persistence to preserve response order.
4. **Reconciliation:** rejected persistence restores the prior state and shows the failure instead of retaining an unconfirmed answer.
5. **Durability:** successful state survives card reload and server restart because it is stored in the ledger card.

---

## E. Pipeline Gate Contract

1. **Source:** `Codebase analysis` emits only questions whose facts remain unresolved after repository, linked-specification, and memory analysis.
2. **Presentation:** `Master task synthesis` writes the CTO brief, persists the questionnaire, and mounts the directive.
3. **Blocking:** Pipeline 2 cannot launch until every blocking question has a persisted answer bound to the current `contextRevision`.
4. **Invalidation:** a changed context revision clears prior responses and returns the lifecycle to operator `Questions`.
5. **Continuation:** automatic enqueueing of Pipeline 2 remains deferred.

## H. Question-Owned Voice Answers

1. **Capture:** every question exposes the native Decision OS voice recorder directly below its free-text answer.
2. **Ownership:** the recorder posts audio to the existing raw `/api/transcribe` route; it never creates or updates a thread note.
3. **Durable state:** `questionnaires[questionnaireId].voiceNotes[questionId]` stores the audio reference, transcript, status, timestamps, and transcription error.
4. **Answer flow:** a successful transcript is inserted into the active question draft and remains editable before the operator submits the custom answer.
5. **Failure:** preserved audio remains attached to the question when provider transcription fails; a missing upload is reported without inventing a durable voice note.
6. **Revision safety:** changing `contextRevision` while voice notes remain is rejected alongside stale text or choice answers.
