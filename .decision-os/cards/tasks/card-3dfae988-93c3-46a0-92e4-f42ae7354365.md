## A. Required Result

1. **Questions source:** render only questions emitted by completed `Codebase analysis`; linked-spec and memory stages never consume unanswered questions.
2. **Question gate:** persist operator answers against the exact Pipeline 1 context revision and authorize Pipeline 2 only when every blocking question is answered.
3. **Solution gate:** present `Problem and solution explanation` with continue and request-revision actions.
4. **QA gate:** preserve explicit QA acceptance and rejection.

---

## B. Completion Signals

1. **Durability:** refresh and server restart preserve questions, answers, explanation decision, QA outcome, and feedback.
2. **Revision binding:** changing analyzed context invalidates its answers; changing the selected solution invalidates its acceptance.
3. **Accessibility:** choices and gate actions are keyboard operable, labeled, focus-safe, and expose validation errors.
4. **Continuation boundary:** automatic enqueueing of the recorded next pipeline remains deferred.
