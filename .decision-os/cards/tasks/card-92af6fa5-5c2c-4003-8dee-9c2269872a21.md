## A. Save Transaction

Reuse revision-aware atomic writes. After content persistence succeeds, create one scoped Git commit and return its revision. If Git commit creation fails, return a contained actionable error and do not claim a new revision. Never include unrelated working-tree changes.

---

## B. Delivery Semantics

After a federated skill commit, invalidate cached export state and publish the refreshed package. Workspace skills remain local. Pipeline prompts remain outside agent discovery and federation, and their Markdown is injected only into the selected pipeline step prompt.

---

## C. Acceptance

1. Stale content revisions return `409` without overwrite or commit.
2. Successful saves survive reload and appear in ordered Git history.
3. Pierre receives deterministic adjacent-revision patches.
4. Rejected saves reconcile to server-confirmed content.
5. Pipeline tests prove explicit prompt injection and zero natural skill visibility.
6. Federation convergence is proven without restarting the server.
