## A. Scope

Reuse the existing revision-aware skill update API and atomic write boundary. After a successful server-owned save, invalidate cached export state and publish the refreshed federation package. Keep local workspace saves outside federation.

---

## B. Acceptance

1. Stale revisions return a conflict without overwriting the file.
2. Successful persistence survives a fresh reload.
3. Rejected persistence reconciles the editor to server-confirmed state.
4. Federation status proves the refreshed package converges without restarting the server.
