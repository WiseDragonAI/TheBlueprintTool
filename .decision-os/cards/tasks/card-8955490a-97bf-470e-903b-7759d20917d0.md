## A. Scope

Compare CodeMirror, Pierre, and the canonical Decision OS Markdown renderer at the document, syntax, range, transaction, rendering, interaction, accessibility, performance, persistence, and lifecycle boundaries.

## B. Deliverable

Select one genuinely unified model where Markdown stays editable and Git additions and removals appear within the same surface. Define range mapping across edits, rendering ownership, semantic Markdown presentation, undo and redo, selection, scrolling, focus, diff refresh, conflict behavior, and cleanup. Separate tabs, independent panes, and source/preview modes are rejected. Do not implement the feature.
