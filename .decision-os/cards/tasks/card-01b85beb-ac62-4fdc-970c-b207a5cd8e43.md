## A. Scope

Codify `SKILL.md` frontmatter `name` as identity and derive replication from the selected source root. Server-owned skills federate; active-workspace skills stay local. The creation checkbox selects that destination explicitly.

---

## B. Acceptance

1. Duplicate and invalid names are rejected deterministically.
2. Root choice is path-contained and visible in the API contract.
3. No new registry, persisted replication flag, or parallel manifest is introduced.
4. Tests prove local skills are excluded and server-owned skills are included in federation exports.
