## A. Scope

1. **Voice-first mobile dock:** Hide the thread textarea by default on viewports up to `760px` and show full-width `FILE`, `TEXT`, and `REC` controls with `REC` at the right edge.
2. **Text mode:** `TEXT` reveals the textarea at `75dvh` and replaces the text-mode control with `SEND`.
3. **Mobile submission:** `SEND` commits through the canonical thread submission effect and returns to the collapsed three-button dock only after a successful commit.
4. **Desktop behavior:** Keep `Ctrl+Enter` submission and its hint on desktop; hide the mobile-only controls.
5. **Mobile status row:** Hide the `Thread input / idle` status row on mobile.

---

## B. Acceptance Criteria

1. **Collapsed state:** The textarea is hidden initially and the dock contains `FILE`, `TEXT`, and `REC` in three equal-width columns.
2. **Voice control sizing:** Each collapsed mobile control is `66px` high, matching the voice recorder controls.
3. **Expanded state:** Tapping `TEXT` focuses a visible textarea with `height: 75dvh` and exposes `SEND`.
4. **Send action:** A successful `SEND` clears the draft and restores the collapsed dock; a failed commit keeps text mode open.
5. **Desktop behavior:** Desktop retains the existing textarea and `Ctrl+Enter` hint without the mobile `TEXT` control.
6. **Verification:** The focused mobile composer integration test and frontend TypeScript check pass.
7. **Status row:** The `Thread input / idle` row is absent at viewports up to `760px`.
