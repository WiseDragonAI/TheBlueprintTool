## A. Gate Objective

1. Run the complete admitted test and typecheck boundary once against the integrated candidate.
2. Group every failure by first causal boundary, shared stack, shared state, fixture, harness, and ownership area.

---

## B. Parallel Investigation

1. Dispatch one low-effort subagent per independent failure group in parallel.
2. Give each subagent exact failing commands, diagnostics, changed files, relevant symbols, and a read-only investigation boundary.
3. Require each report to identify the first incorrect transition, causal evidence, affected tests, shared repair surface, and regression need.
4. Do not edit production code until every dispatched report is available.

---

## C. Exit Condition

1. Produce one complete failure-attribution register with duplicates merged and non-change failures explicitly evidenced.
2. End with `READY_FOR_CONSOLIDATED_REPAIR` when all failure groups have a causal owner and one repair strategy.
