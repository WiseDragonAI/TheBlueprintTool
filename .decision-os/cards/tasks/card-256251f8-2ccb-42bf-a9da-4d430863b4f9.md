## A. Gate Objective

1. Convert the migration request into one concrete source-to-destination contract without inventing requirements.
2. Record repository, branch, worktree, runtime, data, deployment, rollback, and operator-acceptance boundaries.

---

## B. Required Evidence

1. Inspect the supplied brief, linked specifications, current code, durable data shape, runtime state, and existing migration documentation.
2. Name the exact source state, destination state, affected user workflows, public contracts, persisted semantics, failure boundaries, and acceptance commands.
3. Record every unresolved input as one focused operator question.

---

## C. Exit Condition

1. Produce a migration contract containing concrete scope, invariants, exclusions, rollback boundary, acceptance evidence, and verified repository context.
2. End with `READY_FOR_BEHAVIOR_BASELINE` only when no missing answer can change the implementation path.
