1. **Type:** `test`.
2. **Targets:** `frontend/test-responsive/mobile-control-room.test.mjs` and `tests/browser/application/the-application-is-one-responsive-frontend.spec.ts`.
3. **Constraint:** Run every check through `node bin/decision-os-verify.mjs -- <command>`.

## B. Coverage

1. Assert the desktop lane order and simultaneous visibility.
2. Assert queue-format markup and direct navigation across all statuses with no disclosure controls.
3. Assert the grouped Sortable configuration and read-only Exec boundary.
4. Exercise Queue to Backlog and Backlog to Queue payloads, queue rank changes, optimistic placement, reload persistence, and rejection reconciliation.
5. Assert the mobile single-tab contract and width safety remain unchanged.

## C. Completion

1. Focused responsive source-contract checks pass.
2. The browser regression passes with representative desktop pointer input.
3. The regression fails when lane order, unified card structure, cross-lane status persistence, same-lane ordering, rollback, or mobile behavior is removed.
