## A. Cloudflare Failure Contract

1. **Requester disconnect:** Cancel its open remote streams at the owner. A completed owner mutation remains authoritative and is discovered by refresh.
2. **Owner disconnect:** Fail new work with `503 owner_offline`, terminate finite streams, and close bridged SSE so the browser reconnect path retries.
3. **Durable Object restart:** Reconstruct socket identity and persisted membership plus manifests; discard in-flight routes and return an ambiguous outcome for mutations.
4. **Codex continuation:** Requester loss does not kill an owner process; explicit cancellation does. The owner persists run settlement through its existing path.
5. **Git status failure:** A timeout, non-repository result, unsupported worktree state, or parsing failure returns a typed status error and does not fall back to shell output.

---

## B. Git Handoff Failures

1. **Dirty receiving clone:** Do not pull. The owner task records the status and remains blocked until local changes are committed, intentionally discarded by the operator, or reconciled.
2. **Diverged history:** Do not select merge, rebase, reset, or force-push automatically. The owner-side Codex task inspects the commit graph and applies the operator-approved reconciliation.
3. **Rejected push:** Preserve local commits, refresh remote refs, report the rejection, and keep the task active for reconciliation.
4. **Conflict:** Preserve conflict markers, index state, task transcript, and current branch. Do not claim completion until the repository is conflict-free and the intended remote ref contains the result.
5. **Stale status:** Every status explicitly reports local-reference freshness; a relay-cached status is never authoritative.

---

## C. Platform Bounds

1. **Relay:** Admit exactly two node sockets and at most `32` streams per node. Relay `64 KiB` chunks directly and bound unacknowledged data to `1 MiB` per request direction.
2. **Hibernation:** Accepted sockets remain connected without idle duration charges; protocol ping and pong do not wake the object.
3. **Status workload:** Run Git status only for a selected project, coalesce concurrent requests, use a short owner-side cache, cap output bytes, and terminate the child on timeout.
4. **Placement:** Create the federation object with the `apac-se` location hint from the first proof connection.

---

## D. Measurements Required

1. **Federation:** Exercise discovery, mutation, upload, voice, SSE, Codex launch, cancellation, duplicate requests, revocation, reconnect, and owner-offline behavior in both directions.
2. **Git status:** Measure clean, dirty, detached, unborn, conflicted, large-untracked-set, submodule, worktree, non-repository, and timeout cases without leaking raw command output.
3. **Git handoff:** Prove clean push and fast-forward handoff, rejected push preservation, dirty receiver blocking, divergence handling, and conflict reconciliation through owner-side tasks.
4. **Cloudflare and network:** Record requests, CPU, duration, memory, storage, errors, Thailand latency, upload throughput, event latency, and cancellation propagation.
5. **Pass threshold:** No relay buffer exceeds its bound, local project latency remains unchanged within measurement noise, status remains responsive within its timeout, and no Git credential or project content reaches Durable Object storage.
