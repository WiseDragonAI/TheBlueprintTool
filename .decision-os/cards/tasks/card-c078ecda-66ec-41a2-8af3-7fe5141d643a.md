Ledger: Specs

## A. Operator outcome

Create a project by selecting a server-visible local directory. Preserve existing Git and Decision OS state. Initialize missing Git and `.decision-os` state, then register the project in the catalog.

---

## B. Implementation boundary

The directory browser is restricted to the server catalog root, returns directories only, and loads one directory level per request. The browser sends a relative path; the server resolves and validates the real target before filesystem changes.

---

## C. Library decision

Use Node's built-in `fs` and `path` APIs behind a dedicated directory-listing route with a framework-free DOM picker. Browser File System Access handles cannot provide the server-visible absolute path required by this workflow. Full file-manager products add unrelated file mutation, upload, preview, authentication, and deployment surfaces.
