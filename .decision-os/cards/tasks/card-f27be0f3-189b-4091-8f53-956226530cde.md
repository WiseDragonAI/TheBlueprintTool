## A. Corrected Implementation

1. `decisionOsRuntimePlatform` maps `linux -> linux` and `android -> termux`; unsupported hosts fail explicitly.
2. Fresh `resolveCodexCommand` calls inject exactly one normalized platform developer instruction and preserve caller instructions.
3. `resolveCodexResumeCommand` does not inject developer instructions because the original session already owns the platform context.
4. Fresh skill runs, fresh pipeline runs, fresh thread runs, project-sync runs, and continuation fallback new sessions pass through `resolveCodexCommand`.

## C. Lesson

1. Treat process creation and session creation as distinct lifecycle events.
2. Establish immutable runtime context once when the session is created.
3. Preserve established context on resume instead of reinjecting it.
