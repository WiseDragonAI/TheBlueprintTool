## A. Root Cause

1. **Registry evidence:** the workstation registered `Ardaria` at `Ardaria_57` under project ID `Lg`.
2. **Federation evidence:** the phone published a different project named `home` under the same project ID `Lg`.
3. **First incorrect transition:** `federatedProjectCatalog` grouped both rows by project ID and selected the phone row as authority, so the visible `home` row absorbed the local `Ardaria` replica.
4. **Identity distinction:** `Ardaria` has Git origin `git@github.com:ArdariaWorld/client_proto_ue.git`; the phone `home` manifest publishes no origin fingerprint.

---

## B. Applied Repair

1. Unregistered only the local `Lg` catalog entry through the running server; the response confirmed `filesDeleted: false`.
2. Rotated `/home/jbb/Ardaria_57/.decision-os/project.json` to stable ID `927a2e68-e8e4-426f-9f77-fd05a2877bd9`.
3. Re-registered `Ardaria_57` and restored name `Ardaria`, description `The Dream Life - Keep Pushing`, and color `#416be8`.
4. Recovery copies exist at `/tmp/decision-os-projects-before-ardaria-identity-repair.json` and `/tmp/ardaria-project-before-identity-repair.json`.
