## A. Gate Objective

1. Convert the migration plan and accepted audits into an actionable task inventory.
2. Group tasks by proven dependency, shared file ownership, shared runtime state, migration order, fixture ownership, and test harness collision.

---

## B. Required Evidence

1. Give each task an ID, type, title, target files, target symbols, exact change, reason, preservation invariant, completion check, and dependency list.
2. Produce classified dependency edges, independent implementation groups, sequential gates, collision risks, and dispatch notes.
3. Keep every task in one group and keep collision-prone work under one owner.

---

## C. Exit Condition

1. Demonstrate complete coverage from each accepted requirement and audit finding to one task and one implementation group.
2. End with `READY_FOR_GROUP_COMPLETENESS` only when no target file, symbol, dependency, or collision is unresolved.
