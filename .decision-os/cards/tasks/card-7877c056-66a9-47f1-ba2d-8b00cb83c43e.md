## D. Findings

1. **Root cause:** Ordered lists had no card-specific inset on mobile and no ordered-list rule on desktop, so the browser default indentation remained active.
2. **Color gap:** Card list markers inherited the primary text color even though inline backtick code already exposed the requested zone-derived secondary color.
3. **Correction:** Desktop and mobile card styles now set the ordered-list inset to `17px` and explicitly color `li::marker` with each surface's inline-code color token.
