## B. Ownership Rules

1. **Route owner:** project, ledger, zone, card, master task, and subtask routes resolve page destinations.
2. **Layer owner:** thread, process library, process detail, pipelines, pipeline editor, skill picker, and confirmation modal resolve dismissal and predecessor transitions.
3. **History owner:** only the responsive thread layer consumes `history.back()`; page navigation uses the canonical route helper.
4. **DOM boundary:** button datasets carry identity needed by the command; they do not carry mutable navigation policy.

4. Closing the mobile thread preserves the current card route and consumes exactly one responsive history layer.
