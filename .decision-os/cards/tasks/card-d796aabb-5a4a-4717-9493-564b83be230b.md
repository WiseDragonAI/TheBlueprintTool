#master-task

Ledger: Specs

## A. Outcome

1. **Favorites:** Let the operator mark a skill as a favorite from skill detail and keep favorite skills first with deterministic name ordering inside each group.
2. **Skill rows:** Show a larger colored title, description, and bottom-left colored tags; omit ownership, source, workspace, plugin, and favorite metadata.
3. **Tag editing:** Edit persistent skill tags from detail and reuse those tags for the colored row labels and filters.
4. **Responsive detail:** Use shared skill-row and tag presentation contracts while one responsive view-state helper makes detail exclusive and restores the library on Back.

---

## B. Implemented State

1. **Metadata persistence:** Workspace skill-library records normalize `favorite` and `tags`; metadata-only saves preserve defaults and protected `SKILL.md` content, including for system and plugin skills.
2. **Shared presentation:** Desktop and mobile share favorite ordering, stored-tag resolution, tag colors, and the semantic row renderer.
3. **Correct action boundary:** Global Skill Library detail exposes Tags, Save tags, and the favorite toggle; card-scoped Process detail retains run controls.
4. **Correct row boundary:** The row contains only title, description, and bottom tag labels. Ownership and source metadata are not rendered.
5. **Correct detail boundary:** Mobile detail hides tabs, search, filters, clear action, result count, message, and list; Back restores the library view.
6. **Reconciliation:** Favorite and tag mutations update local state before request settlement and reload server-confirmed catalog state after rejection.
7. **Delivery:** Initial favorite merge is `6f90938`; corrected detail/tag merge is `c6edddf`.
