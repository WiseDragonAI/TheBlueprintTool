4. **Focused harness:** `frontend/test-responsive/runtime-status.test.mjs` imports the projection symbols and reads `frontend/index.html`; projection and shell edits cannot be validated reliably against independent intermediate expectations.
5. **Served proof:** T6 names the same four product files as G1 but must remain verification-only; any defect found during served proof must return to the owning implementation group instead of being patched concurrently.
