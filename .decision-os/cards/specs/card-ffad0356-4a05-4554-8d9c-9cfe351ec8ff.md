## A. Deliverable

1. **Agent:** Add an outbound coordinator client without changing existing local HTTP routes.
2. **Identity:** Persist the node key pair outside tracked project state.
3. **Inventory:** Report node platform, version, capabilities, project ID, name, remote fingerprint, SHA, dirty state, active runs, and last sync.
4. **Reconnect:** Retry with bounds and replay unacknowledged terminal status.
5. **Adapter:** Map typed commands to existing local controllers.

---

## B. Acceptance Criteria

1. **Parity:** Inventory contains every locally discovered project exactly once.
2. **Secrets:** Inventory and logs contain no credentials, API keys, private keys, or settings content.
3. **Lifecycle:** Server shutdown closes the session and leaves no child agent.
4. **Recovery:** Network interruption reconnects without duplicate execution.
