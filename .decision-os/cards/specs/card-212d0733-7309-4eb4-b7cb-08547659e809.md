## A. Verified Server Boundary

1. **Single dispatch point:** `backend/src/business/server/helper/create-http-server.ts` resolves `/p/:projectId`, selects that project's `.decision-os` root and runtime, then invokes the existing ledger, asset, upload, event, and Codex controllers.
2. **Single browser boundary:** `frontend/src/runtime/project/helper/project-request-scope.ts` rewrites project-sensitive `fetch` calls, while `subscribe-ledger-content-events.ts` applies the same scope to the ledger `EventSource`.
3. **Finding:** Federation can be inserted at project resolution. Local projects keep the current dispatch path; an owner-qualified remote project is forwarded before a local project context is created.

---

## B. Owner-Dispatch Allowlist

1. **Ledger reads:** Allow `GET /decision-os/state`, `GET /decision-os/:ledgerId`, `GET /api/ledgers/:ledgerId/{canvas,navigation,search}`, `GET /api/ledgers/:ledgerId/cards/:cardId`, and `GET /api/ledgers/:ledgerId/threads/:threadId`.
2. **Ledger mutations:** Allow project-scoped non-`GET /decision-os/:ledgerId` and `POST /decision-os/ledgers`; the owner continues to enforce revision, mutation, and master-completion contracts.
3. **Content and events:** Allow `GET /.decision-os/**`, `GET /api/ledger-content-events`, `POST /api/thread-image-upload`, `POST /api/thread-file-upload`, `POST /api/voice-upload`, `POST /api/transcribe/retry`, and `GET /api/voice-transcription-status`.
4. **Codex:** Allow the existing project-scoped `/api/codex/pipelines**`, `/api/codex/skills**`, `/api/codex/skill-library/**`, and `/api/codex/threads/process` route families.
5. **Node-wide read models:** Allow `GET /api/control-room` and `GET /api/control-room-events`; the requester qualifies every returned project identity before merging it.

---

## C. Forbidden Federation Surface

1. **Node administration:** Reject `/api/server/restart`, `/api/settings/**`, and `/api/debug/**`.
2. **Project administration:** Do not proxy project creation, project metadata mutation, or raw `/decision-os/projects` access. The federation catalog owns discovery; project administration remains local.
3. **Legacy transcription:** Do not proxy `POST /api/transcribe`; the current frontend uses the project-scoped voice orchestration routes.
4. **Verified gap:** `readRequestBuffer.ts` currently buffers without a byte limit. Federation must enforce limits before reading a relayed body.

---

## D. Smallest Adapter

1. **Requester:** At `parseProjectUrlScope`, resolve an opaque project reference to `{ownerNodeId, localProjectId}`. Forward remote requests to the node connector and preserve method, query, allowlisted headers, body stream, cancellation, status, response headers, and response stream.
2. **Owner:** Validate the authenticated requester, owner match, project existence, method/path allowlist, and body limit, then dispatch to the existing loopback `/p/:localProjectId/...` server route.
3. **Result:** No controller is duplicated, and local routes remain unchanged.
