## A. Verified Scope

1. **Desktop task route:** `frontend/src/app/responsive/application.js` deliberately keeps card deep links in the responsive application at widths above `760px`.
2. **Current layout defect:** `frontend/assets/application.css` fixes `.mobile-thread-inspector` and `.thread-panel.agent-chat.phone` to the full viewport, so opening a thread hides the task detail instead of preserving both surfaces.
3. **Reference boundary:** the canvas inspector in `frontend/assets/canvas/shell.css` uses `width: clamp(420px, 33vw, 620px)`.
4. **Shortcut defect:** the responsive application binds only menu `Escape` handling in `frontend/src/app/responsive/application.js`; `frontend/src/app/responsive/thread.js` handles keys only after the thread is already open. The documented `A` and `X` entry commands remain implemented only in `frontend/src/runtime/input/controller/handle-keyboard.ts` for the canvas runtime.
