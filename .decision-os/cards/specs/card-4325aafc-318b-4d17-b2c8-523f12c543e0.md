## A. Scope

1. **Objective:** migrate the complete mobile `Control Room` to the shared voice-derived control system.

---

## B. Requirements

1. **Coverage:** migrate header actions, ledger filters, task summaries, drag handles, subtask rows, task actions, and bottom tabs.
2. **Behavior:** preserve filtering, expansion, task ordering, drag actions, navigation, status display, and elapsed-time behavior in `frontend-mobile/src/mobile.js`.
3. **Consistency:** remove legacy pill-shaped actions except semantic status indicators.

---

## C. Acceptance Criteria

1. **Visual family:** every Control Room action and row uses the shared geometry, depth, typography, and state contract.
2. **Responsive safety:** controls remain usable without overlap at `360px`, `390px`, and `430px` viewport widths.

---

## D. Implementation

1. **Complete:** Control Room headers, filters, task summaries, drag handles, disclosures, subtask rows, actions, and bottom tabs now consume the shared control system without changing their JavaScript workflows.
