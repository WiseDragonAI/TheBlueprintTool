## A. Scope

1. **Objective:** prove design consistency, accessibility, motion safety, responsive layout, and behavior preservation across the redesigned mobile UI.

---

## B. Requirements

1. **Automated coverage:** extend mobile tests for shared classes, semantic states, `44px` targets, reduced motion, overflow safety, and existing workflows.
2. **Visual coverage:** capture `390px × 844px` states for the Control Room, navigation, dialogs, thread tooling, Codex tooling, keyboard focus, and pressed actions.
3. **Viewport coverage:** verify `360px`, `390px`, and `430px` widths.
4. **Research tooling:** use `playwright-interactive` for reproducible visual QA after explicit installation approval; use the Figma skills only after a connected target file exists.

---

## C. Acceptance Criteria

1. **Regression:** the complete mobile test suite passes with task ordering, drag actions, navigation, thread actions, voice capture, Codex processing, and persistence intact.
2. **Signoff:** screenshots show one coherent component family with visible focus, pressed feedback, correct reduced motion, and no overlap.

---
