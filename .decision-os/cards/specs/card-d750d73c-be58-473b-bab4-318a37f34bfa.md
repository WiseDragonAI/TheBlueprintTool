## A. Scope

1. **Aggregate:** load skill and pipeline libraries from every managed project when the global routes open.
2. **Deduplicate skills:** merge identical machine-wide skill records and retain their applicable project identities.
3. **Annotate pipelines:** retain one owning project on every pipeline record.
4. **Preserve requests:** bind pipeline editing and saving to the selected record's project.

---

## B. Acceptance Criteria

1. **No project gate:** `/skills` and `/pipelines` show records before any project interaction.
2. **Machine-wide skills:** shared server, user, system, and plugin skills appear once with all applicable projects.
3. **Project skills:** workspace-specific skills expose their owning project.
4. **Pipeline ownership:** saving a selected pipeline uses its owning project-scoped API.
