Card description content is a first-class file editing surface. Migrated ledgers store card bodies in `.decision-os/cards/<ledger-name>/<card-id>.md` and keep only `comment.contentFile` in the ledger JSON.

Runtime ledger reads hydrate `comment.what` from the content file before returning data to the browser, while edits from the browser and `ledger-cli` write back to the content file instead of embedding the full body in JSON.
