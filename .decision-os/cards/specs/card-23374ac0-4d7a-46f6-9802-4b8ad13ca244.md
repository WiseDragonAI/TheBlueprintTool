#task #task-todo #backend

## A. Deliverable

1. **Service:** Implement the coordinator as a durable HTTPS plus `WSS` service.
2. **Registry:** Persist paired nodes, presence, capabilities, project inventories, and revocation.
3. **Leases:** Implement compare-and-set acquisition, renewal, release, expiry, and audited takeover.
4. **Commands:** Persist `queued`, `assigned`, `acknowledged`, `running`, and terminal transitions.
5. **Audit:** Persist immutable security and execution events.

---

## B. Acceptance Criteria

1. **Presence:** Heartbeats move nodes online and the deadline moves them offline.
2. **Exclusion:** Concurrent acquisition for one project grants exactly one node.
3. **Idempotency:** Repeated submission of one command ID creates one record.
4. **Restart:** Registry, leases, commands, and audit survive restart.
5. **Revocation:** A revoked node cannot connect, lease, receive work, or publish status.
