## A. Deliverable

1. **Audit:** Report missing `origin`, uncommitted project identity, unsupported branch, dirty startup, ignored required state, and missing Git LFS assets.
2. **Manifest:** Stage canonical Decision OS state, work-owned source changes, and referenced managed media.
3. **Handoff:** Implement lease, clean check, fetch, fast-forward, validation, checkpoint, expected-SHA check, push, and release.
4. **Enforcement:** Return `423 Locked` for synced-project mutations without the local lease.
5. **Conflict:** Preserve commits and expose `sync-blocked` diagnostics after rejection.

---

## B. Acceptance Criteria

1. **Hygiene:** Secrets, runtime files, run artifacts, voice uploads, logs, caches, and unreferenced media never enter checkpoints.
2. **History:** The sync path never force-pushes.
3. **Race:** A changed remote SHA blocks publication without losing history.
4. **Reload:** A phone checkpoint fast-forwards on the workstation and survives reload.
5. **Tests:** Cover clean handoff, dirty refusal, lease denial, rejection, asset staging, and secret exclusion.
