## A. Deliverable

1. **Nodes:** Show paired-node presence, heartbeat, platform, capabilities, runs, and revocation.
2. **Projects:** Show per-node availability, SHA parity, dirty state, lease owner, sync time, and diagnostics.
3. **Handoff:** Add acquire, publish, release, refresh, and audited takeover controls.
4. **Remote runs:** Select one eligible node and launch one typed Codex operation.
5. **Feedback:** Stream command plus sync transitions into existing run surfaces.

---

## B. Acceptance Criteria

1. **States:** Expose `in-sync`, `ahead`, `behind`, `dirty`, `leased`, `offline`, and `sync-blocked` clearly.
2. **Guard:** Launch requires one eligible node and one synchronized project.
3. **Optimism:** Submission appears queued before response settlement and reconciles on rejection.
4. **Reload:** Inventory, lease, project, and run status reconcile after refresh.
5. **Access:** Controls are labeled, keyboard reachable, focus-visible, and usable on mobile.
