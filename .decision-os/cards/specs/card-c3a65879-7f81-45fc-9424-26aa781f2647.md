## A. Implemented state transition

1. Backend voice acceptance writes `executionStatus=transcribing-before-launch` before starting provider transcription.
2. Successful transcription hands ownership to the existing Codex launch path, which replaces the transient state with the scheduler state.
3. Failed transcription clears the transient state and leaves the voice note retryable.
