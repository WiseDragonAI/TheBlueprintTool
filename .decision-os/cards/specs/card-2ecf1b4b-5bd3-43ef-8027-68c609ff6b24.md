## A. Request-Path Finding

1. **Eligibility:** `processThreadCodexController` reads the prior run, receives `complete`, and selects `requestCardSkillRunContinue`.
2. **Incorrect transition:** `request-card-skill-run-continue.ts` posts to `/api/codex/skills/runs/<run-id>/continue` without `projectScopedRequestPath`.
3. **Server result:** The exact unscoped POST returns HTTP `400` with `Project id is required in the URL.` on the served server at port `50150`.
4. **Invisible failure:** `handle-action-click.ts` restores the Run controls when the controller returns `false`, while `process-thread-codex-controller.ts` records only telemetry and renders no error.
