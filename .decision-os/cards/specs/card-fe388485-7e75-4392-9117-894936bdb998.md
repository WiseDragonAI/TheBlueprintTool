## A. Study Result

1. **Decision OS federation can use Cloudflare instead of a managed VPS.** Deploy one Cloudflare Worker backed by one SQLite Durable Object for the paired federation; the phone and workstation keep all project files and Codex execution locally.
2. **The operator experience remains symmetric:** either device can discover and operate the other node's projects, while every request and Codex run is routed to the project owner.
3. **A plain Worker is insufficient because it is stateless.** The Durable Object supplies the single coordination point that owns both live node sockets, membership, manifests, presence, and bounded request routing.

---

## B. Smallest Managed Architecture

1. **Ingress:** Both Decision OS servers open authenticated outbound `WSS` connections to a Worker endpoint on `workers.dev` for the proof. The Worker validates the upgrade shape and forwards it to the federation's Durable Object.
2. **Coordination:** One SQLite-backed Durable Object per federation accepts both sockets through the WebSocket Hibernation API. Socket tags and attachments identify nodes; SQLite stores credential hashes, membership, manifests, revocation, and terminal request metadata. No project content is persisted in Cloudflare.
3. **Idle operation:** Cloudflare handles WebSocket protocol ping/pong without waking the object. Hibernation keeps both sockets connected without idle duration billing. Existing `64 KiB` binary chunks remain below Cloudflare's `32 MiB` WebSocket-message limit.
4. **Deployment:** Wrangler owns code, Durable Object migration, and configuration; Cloudflare owns process supervision, TLS, runtime updates, and public ingress. A product deployment uses a Cloudflare custom domain after the proof.

---

## C. Proof Gate

1. **Selected next step:** Build the existing two-node proof on Cloudflare Workers and Durable Objects, not DigitalOcean.
2. **Cloudflare-specific proof risks:** verify explicit credit-based backpressure because the Durable Object WebSocket API exposes no sender queue metric; verify reconnect behavior during runtime replacement; measure Thailand-to-object latency, CPU per message, upload throughput, memory, and billed requests.
3. **Cost boundary:** The current Free plan includes SQLite Durable Objects, `100,000` Worker requests per day, `100,000` Durable Object requests per day, and `13,000 GB-s` of Durable Object duration per day. Hibernation makes the two-node proof a credible free-tier workload, but actual usage must be measured before adoption; the paid Workers plan currently starts at `$5/month`.
4. **Decision required:** Authorize the Cloudflare two-node proof. This study does not authorize product implementation.
