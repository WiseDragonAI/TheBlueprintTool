## C. Sequential Gates

1. **G01 to G02:** G02 can start after the pipeline schema, durable store helper, skill-library defaults, skill discovery metadata, and list/save/detail route contracts exist with the invalid-reference output shape used by saved pipeline runs.
2. **G01 to G03:** G03 can start after `GET /api/codex/pipelines`, `POST /api/codex/pipelines`, `PUT /api/codex/pipelines/:pipelineId`, `GET /api/codex/skill-library/:skillName`, and `PUT /api/codex/skill-library/:skillName` have stable request and response bodies.
3. **G02 to G03:** G03 can complete only after pipeline run start, status, cancel, restart, and resolved model/effort route contracts are stable.
