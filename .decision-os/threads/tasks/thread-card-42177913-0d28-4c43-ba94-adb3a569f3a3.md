The previous swipe implementation was custom. I replaced it with vendored `Embla Carousel 8.6.0` and merged the change in `3cc66b9`.

1. **Selection:** Embla is framework-agnostic, dependency-free, MIT licensed, and provides attraction-based carousel physics. Its official options directly enforce this contract through `slidesToScroll: 1`, `dragFree: false`, and `skipSnaps: false`.
2. **Self-contained delivery:** The pinned `17,946` byte UMD build and MIT license are stored under `frontend-mobile/assets/vendor/`. The application uses no runtime CDN, framework, package manager, or transitive dependency.
3. **Swipe behavior:** The mobile surface no longer runs the custom pointer/`scrollLeft` gesture code. Embla owns dragging and settling with `duration: 25`, `loop: false`, and one snap per movement.
4. **Controls:** Previous, next, and direct selectors now call Embla's `scrollPrev()`, `scrollNext()`, and `scrollTo(index)` APIs. Selected-slide state remains synchronized and persisted.
5. **Lifecycle:** Each Embla instance is destroyed before card content is replaced, preventing stale observers and animation work.
6. **Verification:** `29` mobile tests passed, the focused shared carousel test passed, and frontend TypeScript checking passed. Port `50150` serves the pinned Embla asset with `HTTP 200` and `cache-control: no-store`; no server restart was performed.
