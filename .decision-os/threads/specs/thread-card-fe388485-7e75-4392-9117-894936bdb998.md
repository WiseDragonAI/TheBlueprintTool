## A. Decision

1. **Architecture:** Use a central Decision OS Coordinator as a control plane. Each phone and workstation server becomes an outbound authenticated node while retaining its local project working trees.
2. **State synchronization:** Use one private Git repository per project for source plus canonical Decision OS state. Use coordinator leases and normal fast-forward pushes to keep one active writer and prevent silent history loss.
3. **Remote work:** The phone sends typed Codex commands through the coordinator to a selected workstation. The workstation runs the existing local controller and reports progress plus terminal status.
4. **Finding:** This is an established architecture. Tailscale uses a coordination server with connected device-local data planes, and GitHub self-hosted runners connect outward to receive work and report status.

## A. Cloudflare Decision

1. **Yes: the relay can run without a VPS.** The selected shape is one Cloudflare Worker plus one SQLite-backed Durable Object per federation. A plain Worker is stateless and cannot own both long-lived node connections.
2. **Both Decision OS servers remain symmetric peers.** Each opens one outbound authenticated WebSocket; the Durable Object routes catalog, HTTP, upload, event, and Codex streams to the project owner. Project state and Codex execution never move to Cloudflare.
3. **Operations become substantially smaller:** Wrangler deploys the code and schema; Cloudflare owns TLS, public ingress, process supervision, and runtime updates. Hibernation keeps idle sockets connected without idle duration billing.

---

## B. Proof Boundary

1. **Use `workers.dev` for the two-node proof** with a SQLite Durable Object and `apac-se` placement hint. A later product deployment uses a custom domain.
2. **Add explicit byte-credit flow control.** Cloudflare's Durable Object WebSocket API exposes no relay-side sender queue metric, so the protocol must bound outstanding bytes rather than depend on `bufferedAmount`.
3. **Measure before adoption:** deployed-version reconnect, Thailand latency, CPU per message, memory, `25 MiB` upload throughput, event and cancellation latency, and billed requests. The proof is a credible Free-plan workload; the current paid floor is `$5/month`.
4. **No proof or product code was started.** The next decision is authorization for the bounded Cloudflare proof.
