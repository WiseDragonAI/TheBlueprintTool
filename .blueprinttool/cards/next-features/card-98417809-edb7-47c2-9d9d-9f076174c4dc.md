# CoreV2 Refresh Summaries

## Blueprinttool Context

Blueprinttool is a documentation tool that organizes knowledge on a two-dimensional canvas. A workspace stores ledgers under `.blueprinttool/`. Each ledger contains zones and cards.

Zones are rectangular areas on the canvas. A zone groups related cards and needs a short summary that describes what the zone contains.

Cards are canvas items inside or near zones. Each card can have a long durable body stored in a card body file. A card needs a short summary that describes what is in the card body.

## Purpose

Refresh Blueprinttool card and zone summaries for the active workspace. Use `ledger-cli` to retrieve summary work, generate new summaries from the card or zone content returned by the command, persist the new summaries through `ledger-cli`, and verify that no requested summary work remains.

## Default Target

Use the agent shell cwd as the target workspace by default. Look for `.blueprinttool/` in that cwd first. Do not jump to another directory unless the operator explicitly names it.

If the operator names a workspace, ledger, route, tab, card, or zone, use that explicit target. Otherwise, resolve ledgers from the cwd workspace.

Prefer `.blueprinttool/state.json` for ledger discovery. If no ledger is named, process the active/default ledger when known. If state is ambiguous, process every non-state ledger JSON file under `.blueprinttool/`.

## Resolve CLI

Resolve the CoreV2 runtime repo before using the ledger CLI:

```bash
if [ -n "${COREV2_REPO:-}" ]; then
  COREV2_REPO="$COREV2_REPO"
elif [ -x "bin/ledger-cli.mjs" ]; then
  COREV2_REPO="$(pwd)"
elif git rev-parse --show-toplevel >/dev/null 2>&1 && [ -x "$(git rev-parse --show-toplevel)/bin/ledger-cli.mjs" ]; then
  COREV2_REPO="$(git rev-parse --show-toplevel)"
else
  printf 'Unable to resolve CoreV2 repo. Set COREV2_REPO or run from a CoreV2 checkout.\n' >&2
  exit 1
fi
LEDGER_CLI="$COREV2_REPO/bin/ledger-cli.mjs"
```

## Query Summary Work

Query missing summary work first:

```bash
node "$LEDGER_CLI" missing-summaries --ledger <ledger-json> --json
```

Then query stale summary work:

```bash
node "$LEDGER_CLI" stale-summaries --ledger <ledger-json> --json
```

Use the JSON output as the source of truth for which cards and zones need summaries and what content should be summarized. Do not manually calculate whether a summary is stale. If a command is unavailable, report that exact blocker and the command that must be implemented.

## Generate Summaries

For each missing or stale card summary:

1. Use the card content returned by `ledger-cli`.
2. If the command returns a card body file path instead of body text, read that card body file.
3. Write one to three English sentences describing what is in the card body.

For each missing or stale zone summary:

1. Use the zone content and contained-card context returned by `ledger-cli`.
2. If the command returns card body file paths needed for the zone summary, read those files.
3. Write one to three English sentences describing what the zone contains.

Do not restate only the title. Do not include temporary status such as `working`, `blocked`, `todo`, `done`, or `needs reply` unless that status is the durable subject of the card itself.

## Persist Summaries

Write card summaries through:

```bash
node "$LEDGER_CLI" set-card-summary --ledger <ledger-json> --card-id <card-id> --summary "<one-to-three-sentence summary>"
```

Write zone summaries through:

```bash
node "$LEDGER_CLI" set-zone-summary --ledger <ledger-json> --zone-id <zone-id> --summary "<one-to-three-sentence summary>"
```

These commands persist the new summary. Do not edit summary fields manually in JSON unless the CLI is unavailable and the operator explicitly asks for a manual fallback.

## Verify

After writing summaries, rerun:

```bash
node "$LEDGER_CLI" missing-summaries --ledger <ledger-json> --json
node "$LEDGER_CLI" stale-summaries --ledger <ledger-json> --json
```

Treat the work as complete only when the requested ledgers report no missing or stale summaries, or when remaining entries are explicitly blocked. Report the ledgers checked, summaries written, verification result, and any remaining blocked cards or zones.

## Safety

Only update summaries. Do not change card status, zone geometry, card body text, thread notes, relationships, labels, or unrelated ledger fields while refreshing summaries.

All summaries and agent replies must be in English.
